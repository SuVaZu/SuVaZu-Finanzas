SuVaZu Finanzas — App instalable PWA v0.2

PUBLICAR E INSTALAR (MOTOROLA / ANDROID)
1. Extrae el ZIP y sube los archivos de esta carpeta a un repositorio de GitHub, en la raíz (no subir la carpeta contenedora).
2. En GitHub: Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Abre la dirección HTTPS de GitHub Pages en Google Chrome.
4. Toca «Instalar SuVaZu Finanzas» si aparece; si no, Chrome ⋮ > Instalar aplicación / Añadir a pantalla principal.
5. Podrás abrirla como una app y usarla sin conexión tras cargarla una vez online.

ATENCIÓN: Guardará registros en el almacenamiento local del navegador/PWA. No hay nube ni sincronización; haz respaldos JSON. Si cambias de origen/URL o borras datos de la app, no se trasladan automáticamente. La función de cuadre automático todavía está pendiente.
